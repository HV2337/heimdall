# Heimdall module interfaces

This file is the implementation contract for M2–M4. Implement modules against these names, types, signatures, and failure rules. Do not add raw prompt, patient values, credentials, token values, exception text, or decrypted vault content to logs.

## Shared contracts (`gateway/contracts.py`)

All dataclasses are frozen. `Role` and `TokenType` are `Literal` types. Collections that cross module boundaries are tuples or read-only mappings; implementations must not mutate caller-owned inputs.

```python
from dataclasses import dataclass
from typing import Literal, Mapping, Protocol

Role = Literal["doctor", "nurse", "billing_clerk"]
TokenType = Literal[
    "PERSON", "PATIENT_ID", "PHONE", "EMAIL", "DOB", "DATE", "TIMESTAMP",
    "WARD", "DIAGNOSIS", "VITAL", "MEDICATION", "BILLING_AMOUNT", "NOTE",
    "GOV_ID", "IP_ADDRESS", "API_KEY", "FILE_PATH", "SECRET", "NUMBER",
]

@dataclass(frozen=True)
class RequestContext:
    request_id: str
    user_id: str
    role: Role
    session_id: str

class SafeStageError(Exception):
    code: str
    def __init__(self, code: str) -> None: ...

@dataclass(frozen=True)
class NormalizedText:
    original: str
    matching_text: str

@dataclass(frozen=True)
class ScannableText:
    source: Literal["user_prompt", "retrieved_record"]
    record_id: int | None
    text: NormalizedText

@dataclass(frozen=True)
class ThreatAssessment:
    blocked: bool
    score: float
    source: Literal["user_prompt", "retrieved_record"] | None
    rule_code: str | None

@dataclass(frozen=True)
class SanitizedText:
    text: str
    entity_counts: Mapping[TokenType, int]

@dataclass(frozen=True)
class CheckedOutput:
    text: str

@dataclass(frozen=True)
class AuditEvent:
    timestamp_utc: str
    request_id: str
    session_id: str | None
    user_id: str | None
    role: Role | None
    decision: Literal["allow", "block"]
    blocking_stage: str | None
    threat_score: float | None
    entity_counts: Mapping[TokenType, int]

@dataclass(frozen=True)
class PipelineRequest:
    api_key: str
    session_id: str
    prompt: str
    patient_ids: tuple[int, ...]
    requested_fields: tuple[str, ...] | None = None

@dataclass(frozen=True)
class PipelineResponse:
    request_id: str
    status_code: Literal[200, 403, 503]
    answer: str | None
    message: str

@dataclass(frozen=True)
class PipelineDependencies:
    key_users: Mapping[str, tuple[str, Role]]
    patient_store: "PatientStore"
    classifier: "ThreatClassifier"
    vault: "TokenVault"
    llm: "LLMAdapter"
    audit: "AuditWriter"
    timeout_seconds: float
    token_ttl_seconds: int
    canary_prefix: str
```

`request_id` is newly generated by the orchestrator for every request. `session_id` is issued by trusted server-side session middleware and is bound to the authenticated `user_id`; never accept an arbitrary client value as an authoritative session identifier. A fresh session identifier is required for each isolated conversation. `user_id` and `role` come only from successful API-key authentication.

## Role token resolution policy

The vault may store tokens for every `TokenType`, but output detokenization is constrained by this exact allowlist. Types omitted from a role must remain unresolved and cause output validation to block if the model returns their token. No role may detokenize secrets or infrastructure identifiers.

| Role | Detokenizable token types |
| --- | --- |
| `doctor` | `PERSON`, `PATIENT_ID`, `PHONE`, `EMAIL`, `DOB`, `DATE`, `TIMESTAMP`, `WARD`, `DIAGNOSIS`, `VITAL`, `MEDICATION`, `BILLING_AMOUNT`, `NOTE`, `NUMBER` |
| `nurse` | `PATIENT_ID`, `WARD`, `VITAL`, `MEDICATION` |
| `billing_clerk` | `PERSON`, `PATIENT_ID`, `PHONE`, `BILLING_AMOUNT` |
| All roles | Never resolve `GOV_ID`, `IP_ADDRESS`, `API_KEY`, `FILE_PATH`, or `SECRET` |

## Errors and fail-closed behavior

Each listed module exception derives from `SafeStageError`; its constructor is `ErrorType(code: str) -> None`. `code` is a stable non-sensitive identifier such as `decode_failed` or `model_timeout`. Exception `str(error)` returns only that code. Do not attach causes, exception text, traceback locals, prompt text, patient data, secrets, or token values to errors. Native exceptions and timeouts are translated to the module's named error at its public boundary.

The orchestrator maps authentication, policy, and threat blocks to HTTP-style status `403` with the exact public message `Request blocked.` It maps component faults and timeouts to `503` with the exact public message `Request could not be completed.` It writes a redacted `AuditEvent` for every outcome. If audit writing itself fails, return `503` with `Request could not be completed.` and do not return a model response. No failure path may call the next stage or return partial model output.

## `gateway/normalize.py`

```python
class NormalizeError(SafeStageError): ...

def normalize_text(text: str) -> NormalizedText: ...
```

Apply Unicode NFKC, remove every character whose Unicode category is `Cf`, and decode suspicious segments into `matching_text` for detection only. A base64 candidate is at least 16 consecutive URL-safe or standard base64 characters, optionally ending with at most two `=` characters; pad to a multiple of four and keep a decoded candidate only when strict base64 decoding yields valid UTF-8. A hexadecimal candidate is an even-length run of at least 12 hex digits; keep it only when it decodes to valid UTF-8. Preserve the exact input in `original`. Detection uses `matching_text`; sanitization and prompt construction use `original`. Reject non-string input and translate decoding/normalization faults to `NormalizeError`.

## `gateway/vault.py`

```python
class VaultError(SafeStageError): ...
class VaultExpiredToken(VaultError): ...
class VaultUnknownToken(VaultError): ...

class TokenVault(Protocol):
    def put(self, context: RequestContext, token_type: TokenType,
            value: str, ttl_seconds: int) -> str: ...
    def resolve(self, context: RequestContext, token: str,
                allowed_types: frozenset[TokenType]) -> str: ...
    def clear_session(self, session_id: str) -> None: ...
```

`put` returns a session-scoped opaque marker such as `[PERSON_1]`. Store only AES-GCM encrypted values in memory; obtain a base64-encoded 32-byte key from `HEIMDALL_VAULT_KEY`. Key all entries by `(user_id, session_id, token)` and enforce TTL using a monotonic clock. `resolve` rejects a marker whose stored type is outside `allowed_types`, and raises `VaultUnknownToken` or `VaultExpiredToken` for missing or expired entries. Cryptographic, key, timeout, or storage failures raise `VaultError`. Never fall back to plaintext storage.

## `gateway/sanitize.py`

```python
class SanitizeError(SafeStageError): ...

def sanitize_text(text: str, context: RequestContext, vault: TokenVault,
                  ttl_seconds: int, *,
                  known_names: tuple[str, ...] = ()) -> SanitizedText: ...
```

Find phone, email, government IDs, IP addresses, API keys, file paths, names, dates, timestamps, wards, and domain values using deterministic patterns; `known_names` contains only role-permitted patient names retrieved for this request. Replace PII/sensitive values with typed vault markers. Generalize dates, timestamps, numbers, and wards as required by the spec; report counts by token type only. `entity_counts` contains no matched values. Vault faults propagate as `VaultError`; all other sanitizer faults become `SanitizeError`.

## `gateway/threat.py`

```python
class ThreatError(SafeStageError): ...

@dataclass(frozen=True)
class ThreatModel:
    vocabulary: Mapping[str, int]
    idf: tuple[float, ...]
    coefficients: tuple[float, ...]
    intercept: float
    threshold: float
    model_version: str

class ThreatClassifier(Protocol):
    def scan(self, texts: tuple[ScannableText, ...]) -> ThreatAssessment: ...

def load_model(path: str) -> ThreatModel: ...
```

Run deterministic injection rules and the trained TF-IDF/logistic-regression classifier for every supplied item, including retrieved records. Return the highest classifier score; ties use the earliest item in input order. If a rule or classifier crosses its blocking threshold, set `blocked=True` and provide that item's `source` and a stable `rule_code` (`classifier_threshold` for a model-only block). Otherwise both `source` and `rule_code` are `None`. `score` is in `[0.0, 1.0]`. `ThreatError` covers missing/corrupt artifacts, invalid dimensions/threshold, classifier errors, and timeouts. The JSON format is UTF-8 with top-level keys `format`, `vocabulary`, `idf`, `coefficients`, `intercept`, `threshold`, and `model_version`; `format` is exactly `heimdall-tfidf-logreg-v1`, vocabulary indices are contiguous from zero, and `idf` and `coefficients` lengths equal vocabulary size. NPZ is also allowed if loaded with `allow_pickle=False`. Never load pickle. The VM training script produces the artifact on LinuxONE and records held-out metrics.

## `gateway/output_control.py`

```python
class OutputControlError(SafeStageError): ...

def allowed_token_types(role: Role) -> frozenset[TokenType]: ...

def check_output(text: str, canary_values: tuple[str, ...],
                 role: Role) -> CheckedOutput: ...

def detokenize_output(output: CheckedOutput, context: RequestContext,
                      vault: TokenVault) -> str: ...
```

`check_output` checks raw phone/email/ID/IP/API-key/path patterns, each request canary, and every token marker against `allowed_token_types(role)`. Any detected leak, disallowed/unknown token, malformed output, or scanner fault raises `OutputControlError`; it does not attempt permissive cleanup. `detokenize_output` resolves only markers in the role allowlist. Vault faults propagate as `VaultError`; unresolved or disallowed markers raise `OutputControlError`. Run the raw-pattern and canary checks before detokenization; the policy allowlist is the only route by which intended synthetic record values can be restored.

## `gateway/audit.py`

```python
class AuditError(SafeStageError): ...

class AuditWriter(Protocol):
    def write(self, event: AuditEvent) -> None: ...
```

Append one JSON object per line. Record timestamp, request/user/session IDs, role, allow/block decision, stage, threat score, and entity counts only. Do not record prompts, retrieved text, model output, raw entity values, API keys, canaries, or token maps. File/serialization/permission/timeout failures raise `AuditError`.

## `gateway/main.py` pipeline orchestrator

```python
def run_pipeline(request: PipelineRequest,
                 dependencies: PipelineDependencies) -> PipelineResponse: ...
```

`PipelineDependencies.key_users` maps SHA-256 API-key digests to `(user_id, role)`; it contains no plaintext keys. `PipelineRequest.session_id` must be supplied by trusted middleware and bound to the authenticated user. Execute these stages in exactly this order:

1. Generate `request_id`; authenticate API key; construct `RequestContext`.
2. Resolve `allowed_fields(context.role, request.requested_fields)`; reject unknown or forbidden fields before touching the database.
3. Retrieve only those fields for each `patient_id`; serialize each result for scanning, retaining its record ID.
4. Normalize the user prompt and each retrieved record.
5. Run rules and classifier over the user prompt and every retrieved record. A positive threat result blocks.
6. Sanitize the original user prompt and retrieved record text using the request context and session vault. Pass as `known_names` only names present in fields permitted to this role.
7. Build one prompt from a fixed system instruction, a per-request random canary, the sanitized user prompt, and only sanitized permitted records.
8. Call the configured LLM with `timeout_seconds`.
9. Check model output for raw leaks, canary, and disallowed tokens.
10. Detokenize allowed tokens only.
11. Audit allow decision and return `PipelineResponse(request_id, 200, answer, "ok")`.

On a 403/503 outcome, audit a block event with safe IDs/counts, set `answer=None`, and return a generic `PipelineResponse`. Authentication failures use null user/role in the audit event. A threat block uses status 403 and `blocking_stage="threat"`. Policy/auth failures use 403; component faults including database, normalize, sanitize, vault, classifier, LLM, output-control, and timeout failures use 503. Translate all unexpected exceptions to a generic 503 after attempting a redacted audit write. If audit fails, return 503 with no answer. The existing `GET /health` route remains independent and does not invoke the pipeline.
